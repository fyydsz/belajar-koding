# Dasar-Dasar JavaScript

JavaScript adalah bahasa pemrograman dinamis yang menjadi standar utama dalam pengembangan web modern. Berawal sebagai bahasa skrip di sisi peramban (*browser*), kini JavaScript dapat dijalankan di berbagai lingkungan, termasuk sisi server menggunakan runtime seperti Node.js.

Modul ini dirancang untuk membekali pemrogram dengan fondasi logika dan sintaksis JavaScript modern (standar ES6 ke atas), mencakup pengelolaan data primitif, alur percabangan, fungsi, hingga struktur data koleksi.

## Contoh Kode Pertama

Berikut contoh program sederhana untuk mencetak teks dan menyisipkan variabel menggunakan *template literals*:

```javascript title="halo.js"
const bahasa = "JavaScript";
console.log(`Halo dari ${bahasa}!`);
```

<Callout type="info">
  JavaScript mendukung tanda titik koma (`;`) di akhir setiap baris instruksi. Meskipun sebagian besar lingkungan eksekusi memiliki mekanisme *Automatic Semicolon Insertion* (ASI), menuliskan titik koma secara konsisten merupakan kebiasaan yang baik untuk menghindari ambiguitas kode.
</Callout>
