# Dasar-Dasar Python

Python adalah bahasa pemrograman serbaguna dengan sintaksis yang bersih dan ekspresif. Pendekatan sintaksis Python menitikberatkan pada keterbacaan kode, sehingga pemrogram dapat fokus memecahkan masalah logika tanpa terbebani kerumitan sintaksis tingkat rendah.

Modul ini disusun untuk membangun fondasi pemrograman terstruktur secara bertahap, mulai dari penulisan baris perintah pertama hingga pembuatan fungsi yang dapat digunakan kembali.

## Contoh Kode Pertama

Berikut contoh program sederhana untuk mencetak teks dan melakukan pemformatan data ke terminal:

```python title="halo.py"
nama = "Dunia"
print(f"Halo, {nama}!")
```

<Callout type="info">
  Python mengandalkan indentasi spasi untuk menentukan blok kode dan tidak membutuhkan tanda titik koma (`;`) di setiap akhir baris. Cukup tekan tombol Enter untuk berpindah ke baris baru.
</Callout>
